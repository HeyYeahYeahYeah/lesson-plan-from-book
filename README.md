# lesson-plan-from-book

输入一本教材的书链接 + 课时次数 + 课程标准 Word，自动检索/解析章节目录，参考课程标准，按固定教案模板生成 N 次课时的教案 docx。

## 功能

- 输入「书链接 + 课时次数 N + 课程标准 Word」，自动抓取书名、作者、简介与章节目录
- 参考课程标准（课程目标、教学要求、教学方法、考核方式），生成教案时对齐课标要求
- 把目录按 N 次课时均匀分配，每份对应一次课时的「授课章节」
- 按职业教育教学法（项目教学、做中学）为每次课时撰写：
  - 教学目标（知识 / 能力 / 素质）
  - 重点难点
  - 教学方法
  - 课前准备
  - 教学程序（导入 · 新授内容 · 归纳小结 · 作业，四环节各含「教学内容 + 设计意图」）
  - 教学后记（留空）
- 新授内容按强化规范撰写：每课时 6–8 个要点、约 400–600 字，覆盖原理、结构、分类、选用、应用与课堂互动
- 用 `scripts/build_docx.py` 精确还原「教案模板」的 11 行 × 8 列表格（含合并单元格、宋体 10.5pt 边框）
- 支持可选课程标准 Word 对齐：课程目标、教学要求、教学方法、考核方式对齐到每份教案

## 用法

对话中直接触发，例如：

> 用 https://mall.hep.com.cn/goods-41749.html 生成 3 次课的教案，课程标准是这个 docx

## 目录结构

```
lesson-plan-from-book/
├── SKILL.md               # 工作流、模板字段规范、课时分配算法、撰写规范
└── scripts/
    └── build_docx.py      # 按模板渲染 docx（依赖 python-docx）
```

## 依赖

- `python-docx`（缺失时脚本会自动尝试 `pip install python-docx`）

## 已知限制

- 机械工业出版社 cmpedu.com 的章节目录是动态加载的 PDF 预览，纯 HTTP 抓不到文本，此时需用户从书页「章节目录」复制粘贴目录文本。
- 模板为固定 4 环节结构；如需增加环节，改 `build_docx.py` 的 stages 渲染段。
